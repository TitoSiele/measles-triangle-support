Measles Triage Support Tool

Not a diagnosis. This tool provides decision support only, based on a prototype model with limited real-world validation (especially the image classifier, tested on very few real measles photos). It is meant to assist — never replace — assessment by a qualified clinician. Always confirm findings with proper clinical evaluation and testing.

Public demo notice: This is a demonstration deployment. Do NOT enter real patient information or upload real patient photos.

Symptom Checklist

Unknown is not the same as No. Leave a finding as Unknown (or a number blank) if it was not checked or not recorded. If too many key findings are unknown, the tool will not give a score and will recommend clinical assessment instead.

Rash Photo (optional)

Image assessment has limited validation — treat as a minor supporting signal only. A photo alone will not produce a triage result.
